# My Farmhouse

Modern farmhouse furniture store (portfolio project). Next.js, Tailwind, shadcn/ui, with Sanity, Clerk, Stripe (test mode) and a Gemini shopping assistant planned.

- Plan and phases: [docs/plan.md](docs/plan.md)
- Current status and next steps: [handoff.md](handoff.md)

## Setup

```bash
npm install
cp .env.example .env.local   # then fill in the keys
npm run dev
```

Open http://localhost:3000.
